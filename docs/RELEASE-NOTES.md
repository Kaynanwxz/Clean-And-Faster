## Atualização pelo próprio navegador

- Canal oficial GitHub Releases já configurado: `Kaynanwxz/Clean-And-Faster`.
- Botão **Atualizar**, progresso de download, verificação SHA-256, cópia da versão anterior e reinício.
- Preservação do histórico, favoritos, configurações e perfil de sites.
- Mantidas as correções de encaixe da interface, escala por monitor, abas e diálogos internos.

### Como passar da versão antiga

Em **Menu → Personalizar → Atualizações pelo GitHub**, preencha `Kaynanwxz/Clean-And-Faster`, salve e use **Atualizar**. Se a versão antiga não abrir, baixe `KayBrowser.exe` e substitua o anterior com o navegador fechado. Na nova versão, o canal já vem preenchido.

### Arquivos

- `KayBrowser.exe`: executável Windows x64 autocontido.
- `KayBrowser.exe.sha256`: checksum de integridade.
- `KayBrowser-Windows-x64.zip`: pacote opcional com avisos de terceiros e instruções. Não é necessário para as próximas atualizações.

Requer Microsoft Edge WebView2 Runtime. Login Google precisa de configuração OAuth Desktop; extensões são locais e têm compatibilidade limitada. Ainda é uma prévia. Os resultados dos testes e capturas de layout ficam no workflow do GitHub Actions.
