## Atualizar

No aplicativo, clique **Atualizar → Atualizar e reiniciar**. O executável é baixado, conferido por SHA-256, substituído e reiniciado, sem extrair ZIP. Se usa um canal alternativo, escolha **Canal de atualização → Usar canal oficial**.

## Usar

Abra **Personalizar** na nova aba ou **Menu → Personalizar aparência**. Escolha um visual completo ou ajuste as opções e clique **Aplicar**. **Ctrl+Shift+I** alterna IA; **F8** alterna foco. Botão direito nos atalhos edita/remove; arraste para reordenar.

A IA usa sua chave e saldo da API OpenAI, separada do ChatGPT. Fontes são links salvos, sem verificação automática. Documentos são notas de texto, sem editor Office. Espaços compartilham cookies/perfil. O tema Cristal não usa desfoque contínuo. A RAM é uma meta flexível, sem garantia de teto fixo.
